# Chinar — редизайн сайта

Рабочая реализация нового сайта ресторана: тёмная премиальная тема, glassmorphism,
bento-меню, горизонтальная секция интерьера, бронирование без редиректов и
motion-слой (инерционный скролл, reveal, магнитные кнопки, параллакс).

## Запуск

Сборка не требуется — это ES-модули и чистый CSS. Нужен любой статический сервер
(из-за `type="module"` открытие файла по `file://` не сработает):

```bash
cd chinar
python3 -m http.server 8777
# http://127.0.0.1:8777
```

## Структура

```
chinar/
├── index.html                # каркас секций (контент рендерится из данных)
├── assets/css/tokens.css     # дизайн-токены: цвет, типографика, стекло, движение
├── assets/css/styles.css     # база, типографика, утилиты, reveal, плейсхолдеры
├── assets/css/blocks.css     # блоки: header, hero, концепция, меню, интерьер, бронь
├── assets/js/content.js      # ВЕСЬ контент и медиа-пути (модель = схема CMS)
├── assets/js/render.js       # разметка из данных (будущие React-компоненты)
├── assets/js/motion.js       # smooth scroll, reveal, magnetic, parallax, horizontal
├── assets/js/booking.js      # календарь, слоты, гости, валидация, отправка
├── assets/js/app.js          # точка входа: рендер + инициализация
└── assets/media/             # сюда кладутся реальные фото и hero-видео
```

## Что нужно заменить перед публикацией

Исходный сайт `chinar-restaurant.tilda.ws` недоступен из среды сборки
(заблокирован сетевой политикой), поэтому сайт заполнен **демонстрационным
контентом**: блюда, описания и цены написаны для показа дизайна, телефон и
адрес вымышленные. Всё это лежит в одном файле — `assets/js/content.js`:

| Что | Где | Статус |
|---|---|---|
| Телефон, адрес, часы, соцсети | `CONTENT.brand` | вымышленные |
| Дескриптор и текст «О ресторане» | `CONTENT.hero.lead`, `CONTENT.concept.body` | демо |
| Цифры-факты | `CONTENT.concept.facts` | демо |
| Блюда, описания, цены, категории | `CONTENT.menu` | демо |
| Названия залов | `CONTENT.interior.slides` | демо |
| Юридические данные | `CONTENT.footer.legal` | заглушка |

### Медиа

* **Hero-видео.** Положите `assets/media/hero-16x9.mp4` и `assets/media/hero-9x16.mp4`
  (мобильный кроп 9:16). Приложение проверяет наличие файла `HEAD`-запросом и
  подключает его только при успехе; пока файлов нет — работает анимированный
  фолбэк «угли мангала», без битого кадра. Рекомендация: 6–10 с, без звука,
  H.264 + WebM, до 4 МБ, первый кадр совпадает с постером.
* **Фотографии.** Сейчас на местах кадров лежат сгенерированные атмосферные
  текстуры (`assets/media/*.svg`): тёплые градиенты, дым и блики углей. Это
  не фотографии ресторана — они держат композицию и настроение, пока нет
  съёмки. Замените `src` у `concept.media`, `menu.dishes`, `interior.slides`
  на реальные кадры (AVIF/WebP, кроп по `aspect-ratio` из макета). Если `src`
  оставить пустым, отрисуется заглушка с подписью.

### Приём заявок на бронь

`CONTENT.booking.endpoint = null` — демо-режим: форма валидируется, но ничего не
отправляет и прямо сообщает об этом пользователю. Для продакшена укажите URL
(`/api/booking` или адрес CRM); форма отправит JSON:

```json
{ "name": "…", "phone": "…", "note": "…", "date": "21.09.2026", "time": "19:00", "guests": 3 }
```

## Проверено

Сборка проверена в Chromium (Playwright) на 1440×900 и 390×844:
рендер всех секций, открытие/закрытие меню (клик и `Esc`), якорная навигация
через инерционный скролл, фильтр bento-меню, ховер карточек, календарь с
границами горизонта бронирования, валидация формы и демо-отправка.
Ошибок JS в консоли нет.

Известные ограничения среды (не дефекты вёрстки): шрифты Google Fonts и
hero-видео не загружаются локально — в обоих случаях предусмотрен фолбэк.

## Доступность и производительность

* Уважается `prefers-reduced-motion`: отключаются инерция, параллакс,
  горизонтальный пин и анимации появления.
* Смузскролл не подменяет нативную позицию прокрутки — клавиатура, скроллбар,
  якоря и `IntersectionObserver` работают штатно.
* Скип-линк, `aria-expanded` у бургера, `aria-pressed` у выбора даты/времени,
  `role="alert"`/`role="status"` в форме, видимый `:focus-visible`.
* Изображения — `loading="lazy" decoding="async"`; на `pointer: coarse`
  отключены курсор-компаньон и магнитные кнопки.
